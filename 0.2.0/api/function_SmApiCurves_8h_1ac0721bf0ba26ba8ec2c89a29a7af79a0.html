SmApiCreateCanonicalCurve#

Defined in SM_API/inc/SmApiCurves.h

SmApiStatus SmApiCreateCanonicalCurve(
const SmTArray<SmPoint3d> &crPoints,
const SmTArray<double> &crKnots,
const SmTArray<ULONG> &crKnotMultiplicities,
const SmTArray<double> *crWeights,
ULONG lDegree,
SmBSplineCurveForm eBSplineCurveForm,
SmBSplineCurve *&rpResult,
)#
Parameters:

  • crPoints – [in ]: Points

  • crKnots – [in ]: Knots

  • crKnotMultiplicities –

    [in ]: Knots multiplicities of the end knots must be lDegree+1 and

    : and internal multiplicities must be lDegree or less.

  • crWeights – [in ]: Weights - optional

  • lDegree – [in ]: Degree

  • eBSplineCurveForm –

    [in ]: SM_CF_POLYLINE_FORM, SM_CF_PARABOLIC_ARC,

    : SM_CF_CIRCULAR_ARC, SM_CF_HYPERBOLIC_ARC,

    : SM_CF_ELLIPTIC_ARC, SM_CF_UNSPECIFIED,

    : SM_CF_HELICAL_ARC

  • rpResult – [out]: Resulting SmBSplineCurve
