USD BRep
========

**USD BRep** is a standalone C++ and Python library for boundary representation
(BRep) solid modeling with NURBS and analytic geometry, with native import and
export of BRep data to and from `OpenUSD <https://openusd.org/>`_. It has two
public APIs, each with its own reference below: the ``usd_brep`` Python package
and the C++ headers.
