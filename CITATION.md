# Citation

## Citing USD BRep

If you use USD BRep in a publication, please cite it using the following
BibTeX entry (LaTeX):

```tex
@manual{nvidia2026solidmodeling,
  title        = {USD BRep: Standalone {C++} Library for Boundary Representation Solid Modeling},
  author       = {{NVIDIA Corporation}},
  year         = {2026},
  url          = {https://github.com/NVIDIA-Omniverse/usd-brep},
}
```

Source code is hosted on
[GitHub](https://github.com/NVIDIA-Omniverse/usd-brep).

Adjust the `year` field to match the release or documentation version you
relied on when writing.
